# Project Directory Structure

**Copy this structure to organize your Railway project:**

```
trading-agents/
│
├── 📄 index.js                          ← Main entry point (starts all agents)
├── 📄 package.json                      ← Dependencies
├── 📄 package-lock.json                 ← Lock file (generated by npm)
├── 📄 .env                              ← Environment variables (CREATE THIS)
├── 📄 .env.example                      ← Template
├── 📄 .gitignore                        ← Git ignore rules
├── 📄 Dockerfile                        ← Railway container config
├── 📄 railway.json                      ← Railway deployment config
│
├── 📂 lib/                              ← Core libraries
│   ├── 📄 database.js                   ← PostgreSQL connection & helpers
│   └── 📂 brokers/
│       ├── 📄 binance.js                ← Binance REST + WebSocket API
│       └── 📄 interactive-brokers.js    ← IB Gateway client (Phase 3)
│
├── 📂 agents/                           ← 9 Trading Agents
│   ├── 📂 order-execution-agent/
│   │   └── 📄 index.js                  ← Agent 1: Execute orders
│   ├── 📂 market-data-agent/
│   │   └── 📄 index.js                  ← Agent 2: Stream prices
│   ├── 📂 portfolio-monitor-agent/
│   │   └── 📄 index.js                  ← Agent 3: Monitor drift
│   ├── 📂 risk-management-agent/
│   │   └── 📄 index.js                  ← Agent 4: Validate trades
│   ├── 📂 error-recovery-agent/
│   │   └── 📄 index.js                  ← Agent 5: Handle errors
│   ├── 📂 reconciliation-agent/
│   │   └── 📄 index.js                  ← Agent 6: Daily P&L
│   ├── 📂 notification-agent/
│   │   └── 📄 index.js                  ← Agent 7: Discord alerts
│   ├── 📂 monitoring-agent/
│   │   └── 📄 index.js                  ← Agent 8: System logs
│   └── 📂 queue-manager/
│       └── 📄 index.js                  ← Agent 9: Job queue
│
├── 📂 database/
│   ├── 📄 schema.sql                    ← PostgreSQL schema (10 tables)
│   └── 📂 migrations/
│       └── 📄 001_initial_schema.sql    ← Initial setup
│
├── 📂 config/
│   └── 📄 trading-rules.json            ← Position limits, thresholds
│
├── 📂 logs/                             ← Application logs (auto-created)
│
└── 📂 docs/

    ├── 📄 WEEK_1_IMPLEMENTATION.md      ← What was built
    └── 📄 PROJECT_STRUCTURE.md          ← This file
```

## 📥 How to Set Up Locally

**1. Clone or download all files**
```bash
# Create project directory
mkdir trading-agents
cd trading-agents

# Copy all files from scratchpad to this directory
```

**2. Install dependencies**
```bash
npm install
```

**3. Create .env file**
```bash
cp .env.example .env

# Edit .env with your credentials:
# - BINANCE_TESTNET_API_KEY
# - BINANCE_TESTNET_SECRET_KEY
# - DISCORD_WEBHOOK_URL (optional for now)
```

**4. Create database directory**
```bash
mkdir -p database
mkdir -p agents/order-execution-agent
mkdir -p agents/market-data-agent
mkdir -p agents/portfolio-monitor-agent
mkdir -p agents/risk-management-agent
mkdir -p agents/error-recovery-agent
mkdir -p agents/reconciliation-agent
mkdir -p agents/notification-agent
mkdir -p agents/monitoring-agent
mkdir -p agents/queue-manager
mkdir -p config
mkdir -p logs
mkdir -p docs
```

**5. Copy files to correct locations**
```bash
# Move each agent file to its directory
# Move database files to database/
# Move config files to config/
# Move docs to docs/
```

**6. Test locally (optional)**
```bash
# Install PostgreSQL locally (or use cloud)
npm start

# If using local DB, create it first:
# psql -U postgres -c "CREATE DATABASE trading_agents"
# psql -U postgres -d trading_agents -f database/schema.sql
```
